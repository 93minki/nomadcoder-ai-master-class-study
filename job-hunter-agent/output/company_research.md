# Company Overview
**쓰리빌리언 (3billion)**
- 설립연도: 2016년 10월
- 본사: 서울 강남구 테헤란로 416, 14층
- 직원수: 약 100명 (2025년 기준)
- 산업군: 의료 · 바이오 · AI (희귀질환 유전자 검사 및 해석 솔루션)
- 주요 서비스:
  - 한 번의 검사로 7,000여 종 희귀질환 진단
  - AI·빅데이터 기반 유전체 분석 플랫폼 (예: 3B‐EXOME, 3B‐GENOME, 3B‐INTERPRETER, GEBRA™)
- 투자 및 재무 하이라이트:
  - Series C 투자 유치 완료 (140억 규모)
  - 2024년 코스닥 상장
  - 누적 환자 검사 6만 건 돌파(2024.12)

## Mission and Values
**Mission**
“희귀질환 환자들이 진단과 치료에서 외면받지 않는 세상”
- 빠르고 정확한 진단 제공
- 진단 소요 시간·비용 획기적 단축

**Core Values**
- *Growth Mindset*: 충분한 학습 기간 제공, 새로운 전문지식 습득 장려
- *Psychological Safety*: 자유로운 의견 개진, 수평적 커뮤니케이션
- *Work–Life Balance*: 탄력 근무·시간 단위 연차로 개인 설계 가능
- *Collaboration*: 바이오·의학·엔지니어링이 융합된 팀워크

## Role Context and Product Involvement
**포지션**: 신입/주니어 프론트엔드 개발자 (React 중심)
**주요 업무**
- 고객 접점 웹 서비스 개발 (환자/의사용 포털, 리포트 대시보드)
- 사내 인프라 시스템 UI 개발 (관리자용 어드민 털)
- 기존 서비스 유지보수 및 퍼포먼스 최적화

**기술 스택 예상 구성**
```
- Frontend: React (Hooks, Context API), HTML5, CSS3, ES6+
- 버전 관리: Git (branch 전략, PR 리뷰 프로세스)
- 테스트: Jest, Mocha, Storybook (우대)
- 배포/호스팅: AWS (S3, CloudFront, Lambda 등)
- CI/CD: GitHub Actions or AWS CodePipeline
```

**팀 구조 (추정)**
- 프론트엔드 엔지니어 3~5명
- 백엔드/데이터 사이언티스트 협업
- UX/UI 디자이너 1~2명
- 제품 PO, QA, DevOps 포함 크로스펑셔널 스쿼드

## Likely Interview Topics
1. **React & JavaScript Fundamentals**
   - Hooks (useState, useEffect)와 custom hook 설계
   - 컴포넌트 구조화 및 상태 관리 전략
   - 비동기 처리(Promise, async/await)
2. **HTML5 & CSS3**
   - 시멘틱 태그 활용, 접근성(a11y) 고려
   - 레이아웃(Flexbox, Grid) / 반응형 디자인
3. **Version Control (Git)**
   - Branch 전략(Feature, Release, Hotfix)
   - Pull Request 리뷰 워크플로우
4. **AWS 배포 기초**
   - 정적 사이트 호스팅 (S3 + CloudFront)
   - Lambda, API Gateway 기본 이해
5. **테스트 & 품질 보증**
   - 단위 테스트/Jest, 컴포넌트 테스트/Storybook
6. **문제 해결 & 알고리즘**
   - 간단한 알고리즘(배열·객체 조작, 정렬)
   - 디버깅, 성능 최적화 사례
7. **Behavioral & Culture Fit**
   - 새로운 도메인(바이오·의학) 학습 경험
   - 수평적 팀 분위기에서의 소통 방식
   - 심리적 안정감을 위한 피드백 주고받기 경험

## Suggested Questions to Ask
1. **엔지니어링 조직**
   - 프론트엔드 팀 규모와 구조는 어떻게 되나요?
   - 코드 리뷰와 배포 프로세스는 어떤 툴과 방식으로 운영되나요?
2. **온보딩 & 도메인 교육**
   - 바이오·유전체 분야 지식 학습 지원 체계가 있나요?
   - 멘토링·스터디 그룹 세션은 어떻게 운영되나요?
3. **기술 로드맵**
   - 장기적으로 신규 웹 기능이나 마이그레이션 계획이 있나요?
   - TypeScript 전환 계획 혹은 PWA 도입 논의가 있나요?
4. **문화 & 커뮤니케이션**
   - 수평적 문화라고 하는데, 일상적인 피드백 루프는 어떤 형태인가요?
   - 심리적 안정감을 높이기 위한 팀 활동이 있나요?
5. **Career Growth**
   - 신입/주니어 엔지니어의 성장 경로와 기대 시기는 어떻게 설정되나요?
   - 성과 평가 및 승진 기준에 대해 알려주실 수 있나요?
